# Módulo Observability

Este módulo será responsável pela observabilidade da arquitetura AWS.

## Recursos Futuros

- CloudWatch Logs.
- Métricas.
- Alarmes.
- Dashboards, se necessário.

## Observações

Logs e métricas devem cobrir EC2, containers, ALB, RDS e WAF quando os recursos forem implementados.
